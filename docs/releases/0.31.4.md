# Aru Host 0.31.4

这次修复 Windows 预览版的两个阻断问题和模型 API 驱动的一处工具调用中断，建议 Windows 用户和使用「模型 API」电脑协作者的用户更新。

- 修复 Windows / Linux Console 在对话页发消息和处理审批时报 `unknown route`。Console 之前用 `PUT` 请求，而 Host Core 只接受 `POST`，自 0.31.0 起 Console 内发送一直失败。macOS Console 不受影响。
- 修复 Windows 上通过 `npm install -g` 安装的 Codex / Claude Code 探测不到驱动、本地状态显示 `version-probe-failed`。Node 拒绝直接启动 npm 生成的 `.cmd` 文件，Host 现在改为用自带的 Node 启动该文件指向的 JavaScript 入口，不经过 cmd.exe，中文用户目录可用；探测会试完全部候选路径，失败原因记录在 `failureDetail`。
- 修复「模型 API」电脑协作者一使用工具就报「模型返回了无法读取的工具参数」并中断整轮。空参数和对象形式的参数视为合法；无法解析的 JSON 作为工具错误回给模型重试，连续三轮仍不可读才停止；参数被单次回复预算截断时明确报出原因；被截断的工具批次在执行前拒绝。
- 协议仍为 `stub-0.30`，本次没有数据迁移。手机端不需要更新。

## 下载与升级

直接安装新版，无需先卸载。提供 Apple 签名、公证的 macOS 26+ 通用 DMG、Windows 10/11 x64 未签名预览 EXE，以及 Debian/Ubuntu x64、arm64 DEB。每个安装包附带 SHA-256 和 JSON 版本记录。手机端不会随 Host 自动更新。
