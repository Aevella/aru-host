# Aru Host 0.32.0

这一版让新版 Aru 直接从手机管理电脑协作者的模型配置，并收齐 0.31.4 之后的 Host 修复。协议仍为 `stub-0.30`，没有数据迁移。

- 在已配对的 iPhone 上新建、编辑、测试和删除「模型 API」配置，并直接新建电脑协作者。密钥只写入电脑的系统安全存储，接口不返回密钥；把配置改到另一个接口地址时重新填一次 key。重复提交同一次创建不会产生重复的配置或协作者。
- 无需密钥的本地模型配置可以正常使用，没有系统安全存储的 Host 也能保存和运行这类配置。
- 结果通知可以登记为官方中继路线：Host 只把消息定位信息交给中继，不发送回复正文。直连 APNs 的登记方式不变。通知带后台唤醒标记，手机协作者在电脑上完成的投递可以在后台导入。
- 修复 Debian/Ubuntu 上系统安全存储被误判为不可用，之前的探测用了 `secret-tool` 并不支持的 `--version` 参数。
- 插件安装带安装回执，网络重试不再误报「已安装」。
- Windows 卸载先移除 `current` / `previous` 链接，再删除发布目录。
- Host Core 源码按职责拆分到 `src/`，安装使用的固定文件由构建生成，已安装的 0.31.x 可以直接升级到本版本。
- 对话中转的请求校验与原始回复文件管理各自独立，回复内容与状态语义不变。

## 与手机端的配套

- 手机上管理模型配置、新建电脑协作者，需要 Aru TestFlight 0.3 (202609160540) 或更新版本。旧版手机照常配对使用，只是没有这些入口。
- 经官方中继送达结果通知，还需要官方中继升级到接受 Host 结果路线的版本，随后单独上线。
- Host 和手机谁先更新都可以。

## 未包含

- Host 数据的 SQLite 存储迁移仍在单独开发，本版继续使用现有状态文件。
- Claude Code 驱动的执行功能。
- 通过终端管理 VPS 上的模型密钥。

## 下载与升级

直接安装新版，无需先卸载。提供 Apple 签名、公证的 macOS 26+ 通用 DMG、Windows 10/11 x64 未签名预览 EXE，以及 Debian/Ubuntu x64、arm64 DEB，每个安装包附带 SHA-256 和 JSON 版本记录。

VPS 用 `sudo aru-selfhost upgrade` 升级，升级前会先检查现有数据，数据无法读取时不切换版本。需要回退时运行 `sudo aru-selfhost rollback`，身份、配对和数据保留，经中继登记的通知需要手机重新登记一次。手机端不随 Host 自动更新。
