# Aru Host 0.39.1

本版修复 Linux 容器就绪检测、Windows 首次安装和配对失败提示，并改善电脑端对话与附件恢复。

- Linux rootless Podman 无法取得 cgroup 权限时，先验证不带资源限制的运行方式，必要时再验证禁用 cgroup。成功后容器能力继续可用，具体降级原因保留在诊断中。
- 配对失败分别返回已使用、已过期和不匹配的原因。服务重启后请重新生成配对链接；旧链接不会复用。
- Windows 创建 Node 目录联接失败时，可直接使用已解压验证的版本目录；异常说明具体路径，重试可发现已有运行时。
- 修复 Console 备份仓、审批窗口与对话增量同步请求被错误拦截。
- Claude Code 工具等待人工审批时不再受隐式 HTTP 响应头超时影响；结束或失败的回合会释放审批等待，迟到的回调不能继续执行旧回合。
- 修复附件分块写入与损坏分块重试；附件准备失败会结束本次任务，后续消息可继续发送。
- 同一手机协作者重新配对后的只读资料同步可恢复，旧设备迟到更新不会覆盖新关系；过滤回复投影中的独立时间戳信封，原始记录保持不变。

## 更新

Mac 替换 DMG 中的应用并按提示更新 Core；Linux 使用对应架构 Debian 包或既有升级命令；Windows 提供 x64 未签名 preview。无需卸载、解绑或删除数据。发布不会自动升级正在运行的服务器。

无限制降级会失去容器级 CPU、内存和进程数限制，管理员可在诊断中确认并修复 cgroup 委派。手机端的细分配对提示和多地址工具线路选择需要相应手机版本；仅更新 Host 不会改变旧手机的线路选择。

## 验证范围

候选以 Host Core、安装恢复、Console 和生成部署文件一致性检查为基础，并增加 Ubuntu 24.04 系统级服务下 rootless Podman/runc 的委派与无委派检查，以及 Windows junction 故障注入。各平台安装包继续由发布流水线完成构建、检查和资产校验，macOS 完成签名公证。以流水线实际成功结果为发布依据，不将合成故障测试描述为客户原机复现。
