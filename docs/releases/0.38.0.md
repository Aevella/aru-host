# Aru Host 0.38.0

本版收拢安装启动、手机托管和容器任务的失败恢复。

- Console 启动、重启和修复共用安装检查；Windows 计划任务缺失时可以进入修复，注册失败也会进入恢复出口。
- macOS/Linux 服务激活失败不会再被旧进程的健康响应掩盖。
- 手机托管执行不再等待通知投递；取消后不会继续启动排队请求。失败时保留部分结果，保存结果失败只重试保存，不重新调用模型。
- 插件容器控制改为异步，停止或删除失败不再报告成功，仍可继续处理或重试。
- 工作区旧容器清理失败只影响对应任务，启动恢复不会阻挡 Host 提供服务；清理等待期间的取消不会被迟到结果覆盖。

## 更新

Mac 下载 DMG 替换应用，再按提示更新 Console 管理的 Core。Linux 提供 x64/arm64 Debian 安装包。
Windows 提供 x64 **未签名 preview** 安装包。
无需卸载、解绑或删除现有数据。发布安装包不会自动升级正在运行的服务器。

## 验证范围

修复提交通过 Host core、真实容器与旧包兼容、Linux 桌面包安装、macOS 15/26 检查。
Windows 验收覆盖实际计划任务注册拒绝、失败恢复、重启、回滚及恢复失败报告、DPAPI、保留数据重装，以及 NSIS 安装后启动。
发布流水线另行验证 macOS 签名/公证、Linux 两种架构安装和全部发布资产 SHA-256。

自动化环境验证不代表每台客户设备已验收；锁屏外部唤醒、特定 Ubuntu 环境及此前完成后改判失败的现场反馈仍需对应证据，不能据此全部结案。
