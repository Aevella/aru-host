# Aru Host 0.32.0

这次整合 0.31.4 之后已完成的 Host 修复，并让新版 Aru 可以从已配对的手机管理电脑协作者的模型配置。协议仍为 `stub-0.30`，没有数据迁移。

- 从已配对的 iPhone 新建、编辑、测试和删除「模型 API」配置，并直接新建电脑协作者。密钥只写入电脑的系统安全存储，接口不会返回密钥；手机把已有配置改到另一个接口地址时需要重新填写 API key。重复提交同一次创建不会产生重复的配置或协作者。无需密钥的本地模型配置（例如本机模型服务）现在可以实际运行。
- 结果通知可以登记为官方中继路线：Host 只把消息定位信息交给中继，不发送回复正文。旧版手机的直连 APNs 登记方式不变。通知会携带后台唤醒标记，手机可以在后台导入手机协作者在电脑上完成的投递；电脑协作者的结果仍在点开通知后从 Host 读取。
- 修复 Debian/Ubuntu 上系统安全存储被误判为不可用：探测不再依赖 `secret-tool` 并不支持的 `--version` 参数。
- 插件安装带有安装回执，网络重试不会误报「已安装」。
- Windows 卸载先移除 `current` / `previous` 链接，再删除发布目录。
- Host Core 源码按职责拆分到 `src/`，安装使用的固定文件由构建生成；已安装的 0.31.x 升级器可以直接升级到本版本。
- 对话中转的请求校验与原始回复文件管理独立出来，回复内容与状态语义不变。

## 与手机端的配套

- 在手机上管理模型配置、新建电脑协作者，需要 Aru TestFlight 0.3 (202609160540) 或更新版本。旧版手机仍可正常配对和使用，只是没有这些入口。
- 经官方中继送达结果通知，需要同样的手机版本，**并且需要官方中继上线接受 Host 结果路线的版本**。本次发布只包含 Host 这一端；中继上线前，这条通知路线不会送达，已有的直连方式不受影响。Host 记录的「已送达」只表示中继已接受请求，不代表手机已收到或已打开。
- 先发布 Host 或先更新手机都可以，二者互不阻断。

## 未包含

- Host 数据的 SQLite 存储迁移仍在单独开发，本版继续使用现有状态文件。
- Claude Code 驱动的执行功能尚未完成真实账号验收（成功回复、续接、工具确认、取消），本版不提供。
- 通过终端管理 VPS 上的模型密钥（无头配置）未包含。

## 下载与升级

直接安装新版，无需先卸载。提供 Apple 签名、公证的 macOS 26+ 通用 DMG、Windows 10/11 x64 未签名预览 EXE，以及 Debian/Ubuntu x64、arm64 DEB。每个安装包附带 SHA-256 和 JSON 版本记录。VPS 使用 `sudo aru-selfhost upgrade` 升级；升级前会先检查现有数据，数据无法读取时不会切换版本。升级后需要回退时可运行 `sudo aru-selfhost rollback`，身份、配对和数据保留，只有经中继登记的通知需要手机重新登记。手机端不会随 Host 自动更新。
