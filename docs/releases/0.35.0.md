# Aru Host 0.35.0

本版支持 macOS 15（Sequoia）及以上系统，并更新 Windows、Linux 的配套 Host 安装包。

- Mac Console 在 macOS 26 保留 Liquid Glass，在 macOS 15 使用系统材质，保持现有布局和交互。
- 新增加密增量备份，重复内容可复用加密块，发布与删除保留可恢复记录；手机需要支持对应协议才能使用，旧备份仍可读取。
- 插件编辑器支持可选作者信息，保存、发布和列表展示保留原作者填写的内容。
- Windows/Linux Console 自动显示聊天中的待审批操作，按消息身份更新变化内容，保留输入框与滚动位置。
- 修复备份删除入口：非法名字返回 400，不存在的备份返回 404，避免误报服务器故障或删除成功。
- 修复 Linux 容器自检受 UMask=0077 和私有临时目录影响的问题，保留内存、CPU 和进程数限制。
- 增加手机上传中断的诊断，未完整上传的请求不会进入执行，日志不记录请求正文或凭据。

## 更新

Mac 用户下载 DMG 并替换应用，打开后按提示更新由 Console 管理的 Host Core。不需要卸载或删除数据。独立安装的 Host 仍通过原安装方式升级；手机与 Host 更新分开。

Linux 提供 x64、arm64 Debian 安装包。Windows 提供 x64 未签名 preview 安装包。VPS 安装器可使用本版 tag；不会因发布安装包自动升级已经运行的服务器。

## 验证

源码 CI 已通过 Host 核心、Linux 桌面和 macOS 15/26 检查。Linux VPS 以真实服务用户、UMask=0077 和保留资源限制运行隔离自检：旧代码复现 EACCES，修复版 Node/Python/Shell 读写全部成功，8 个聚焦测试通过；正式服务没有重启或升级。该 VPS 使用 OpenCloudOS，不能替代报告者 Debian/rootless cgroup 环境验收。

发布流水线另行执行 macOS Developer ID 签名、公证、Gatekeeper 检查，Windows/Linux 安装检查及 12 个发布资产的校验和核对。源码检查不等于安装包已发布；实际发布结果见 GitHub release。Windows 仍为未签名 preview。
