# Aru Host 0.31.1

这次小版本让 macOS 上的 Aru Host 拥有正式、清晰的应用图标，同时收进 0.31.0 之后已经公开的私网触发发送器兼容更新。Host 协议仍是 `stub-0.30`，已有协作者、配对、页面、权限和数据不需要迁移。

## 下载哪个安装包

| 设备 | 下载文件 | 发布状态 |
| --- | --- | --- |
| Mac（macOS 26，Apple Silicon / Intel 通用） | `aru-host-macos-0.31.1.dmg` | Developer ID 签名与 Apple 公证 |
| Windows 10 / 11，x64 | `aru-host-windows-0.31.1-x64.exe` | **预览版，尚未代码签名** |
| Debian / Ubuntu 桌面，x64 | `aru-host-linux-0.31.1-x64.deb` | 桌面安装包 |
| Debian / Ubuntu 桌面，arm64 | `aru-host-linux-0.31.1-arm64.deb` | 桌面安装包 |

每个安装包都有同名 `.sha256` 校验文件和 JSON 版本记录。Windows 预览包可能出现系统信誉提示；它仍不具备可验证发布者的代码签名，也没有 Windows arm64 包。

## 更新

- macOS Console 现在显式打包专属的高分辨率 Aru Host 图标，并在应用元数据中声明图标与生产力工具分类。图标是受版本控制的构建输入，不依赖发布机器临时生成。
- 独立唤醒发送器可以向已经配对的 LAN 或 Tailscale Host 提交端到端加密事件，同时继续拒绝未配对的普通 HTTP 地址、重定向和不安全的公开地址。
- Windows、Linux 和 Host Core 的功能基线保持 0.31.0 的责任边界；本次没有数据格式或 Host 协议迁移。

## 升级与验证范围

Mac 用新应用替换“应用程序”里的 Aru Host；Windows 运行新版安装包；Linux 安装对应架构的新版 `.deb`。常规升级继续复用原有用户数据目录，不需要先卸载，也不需要重新配对。

Host 协议保持 `stub-0.30`。发布流水线会重新验证 Host HTTP/MCP、macOS Console 与签名公证、Windows 安装生命周期，以及两个 Linux 架构的安装和真实容器任务。Windows 仍是未签名预览版；Linux 容器成功不等于 Windows 虚拟机接入已经在每台设备上完成。
