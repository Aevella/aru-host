# Aru Host 0.31.3

这次修复一条可能覆盖本地状态的数据安全问题，建议更新。

- 旧版本遇到无法读取的 `state.json` 时，可能创建空状态并在启动时覆盖原文件。新版遇到读取失败、无效 JSON 或无效的根身份/集合结构会停止启动，保留原文件。
- 安装器在切换版本前使用新版读取器进行只读检查，避免检查失败后退回旧版本启动。
- Console 显示状态读取失败的说明。检查权限或从已验证的备份恢复后，可以重试；不要删除数据目录或使用清除数据的卸载方式。
- 正常首次安装与有效旧状态仍可使用。本次不迁移数据格式，协议仍为 `stub-0.30`。

本次保护阻止后续覆盖，不会自动找回此前已经被覆盖的元数据，也不等于完整的存储损坏恢复系统。

## 下载与升级

直接安装新版，无需先卸载。提供 Apple 签名、公证的 macOS 26+ 通用 DMG、Windows 10/11 x64 未签名预览 EXE，以及 Debian/Ubuntu x64、arm64 DEB。每个安装包附带 SHA-256 和 JSON 版本记录。手机端不会随 Host 自动更新。
