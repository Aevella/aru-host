# Aru Host 0.39.2

本版修复删除电脑协作者后又出现在列表、页面刷新提示 `unknown hosted collaborator` 的问题。

- macOS 和 Windows/Linux 桌面 Console 的列表、计数与后续详情读取排除已删除协作者；删除后刷新或重新打开不再把已删除条目显示回来。
- 保留已有对话、页面、记忆和同步删除标记；重复删除仍可安全返回，不会恢复已删除身份。
- 手机协作者委托 Host 主动执行时，历史上下文按 64 KiB UTF-8 预算保留最近连续消息，避免超长历史挤爆请求；完整同步依据、执行记录和投递回执保持不变。这不是模型总上下文上限，其他材料仍可能超过供应商限制。

## 更新

Mac 下载新版 DMG，替换应用并按提示更新 Core。已经删除过的协作者会在新版列表中正确消失，无需卸载、解绑或清空数据。
Linux 使用对应架构 Debian 包或既有升级命令；Windows 提供 x64 未签名 preview。发布不会自动升级正在运行的服务器。

## 验证范围

删除链的本地聚焦检查覆盖删除失败保留、重复删除、磁盘删除标记、刷新与重新打开、其他正常协作者及旧 Host 缺省字段。手机历史预算检查覆盖 Unicode、超长消息、供应商失败、下一次调度与重复回执。
各平台包由发布流水线构建并核验，macOS 完成 Developer ID 签名与公证；实际发布以流水线成功和资产校验为准。合成测试不代表客户原机验收，也不代表真实模型生成质量验证。
