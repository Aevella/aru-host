# Aru Host 0.39.0

本版修复容器运行环境启用无效和托管回复重复通知，并补齐常驻 Claude Code 会话与手机授权 MCP 代执行。

- 重新配对后，同一个手机协作者的更新只读资料可交接给新设备身份；旧设备迟到上传不会覆盖新状态，电脑本身的记忆不变。
- 从安装目录的 current 符号链接或 Windows junction 启动时，容器配置脚本现在会实际执行检测、验证和配置保存；此前入口可能直接成功退出，Core 却一直显示 unconfigured。验证失败保留旧配置，可修复后重试。
- 运行环境验证报告 Core 的具体失败；卡住的验证可结束并重试。
- 托管回复完成时只发送一条可见通知；Live Activity 收尾保持静默。
- API 工具续接保留推理内容，手机投递剥离被回显的时间元信息。
- Claude Code 同一会话跨回合复用进程，权限与工具回执逐轮隔离；空闲回收后仍可恢复持久会话。
- 手机明确授权并同步的外部 MCP 可由 Host 代执行；凭据加密保存、故障按连接隔离、撤销先阻断执行再清理。OAuth 到期仍需手机重新授权并同步。
- Console 提供电脑协作者删除入口，并遵循已有生命周期校验。

## 更新

Mac 替换 DMG 中的应用并按提示更新 Core；Linux 使用对应架构的 Debian 包或既有升级命令。Windows 提供 x64 未签名 preview。无需卸载、解绑或删除数据。已运行的服务器不会随发布自动升级。

MCP 代执行需要支持该配置的手机版本，并在手机执行“同步配置与 MCP”；只升级 Host 不会自动授予凭据或开启授权。已有容器启用失败可在更新后重新点击“检测并启用”。

## 验证与范围

本地 Host Core 与 Electron Console 共 269 项检查，267 通过、2 项平台相关跳过；包括通过安装链接执行配置入口的真实子进程验证。macOS Console 51 项测试、APNs 通知、Claude Code 工具桥、对话、托管及 macOS 安装 smoke 均通过。发布流水线继续验证 Windows junction、计划任务与 DPAPI、macOS 签名公证、Linux 安装及发布资产校验。流水线结果以实际发布记录为准。

没有把客户设备验收当作自动化结果。首次 Windows 安装 junction 创建失败、锁屏取件与通知后正文同步延迟仍需各自证据；本版不宣称全部解决。真实 Claude 账号多轮生成和手机离线 MCP 执行仍待实机验收。
