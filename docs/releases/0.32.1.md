# Aru Host 0.32.1

这一版只修托管回复的三处，没有新功能。协议仍为 `stub-0.30`，没有数据迁移。

- 修复对话变长之后托管请求被 Host 以 HTTP 400 拒收的问题。原因是 Base64 校验用了按四字符重复匹配的正则，请求体大到一定程度就把 V8 的正则栈撑爆；手机收到 400 后会悄悄退回本地生成，一离开前台回复就断。现在改为解码后重新编码比对，格式错误仍会被拒绝。
- Host 日志会记录拒收原因类别和编码后的大小，不记录请求内容。
- 托管的一轮回复在 Host 上完成、手机还没来取时，Host 会叫醒提交这一轮的手机来取，回复在你重新打开 Aru 之前就已经在对话里。推送只带 Host 身份、手机对话 id 和回合 id；经官方中继登记的手机走中继，直连登记的走 APNs。

## 与手机端的配套

- 收到唤醒并自动取回，需要 Aru 0.3 (202609220010) 或更新版本；旧版手机会忽略这条推送，其余行为不变。
- 经官方中继唤醒需要中继已升级到接受转发回合结果路线的版本，`wake.aelion.cn` 已于 2026-09-21 完成。
- Host 和手机谁先更新都可以。

## 未包含

- 手机在请求组装阶段被系统结束时的回合恢复。
- 工具调用中间轮次的后台续跑。

## 下载与升级

直接安装新版，无需先卸载。VPS 用 `sudo aru-selfhost upgrade` 升级，升级前会先检查现有数据，数据无法读取时不切换版本。需要回退时运行 `sudo aru-selfhost rollback`。
