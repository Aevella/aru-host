# Aru Host 0.37.0

本版改善连接、凭据和任务执行的失败恢复，支持对话附件断点续传。

- Codex 初始化失败后可以重新连接；启动挂住可以取消，旧连接的迟到结果不会干扰新连接。
- 手机主动任务遇到暂时存储故障后可在同一 Host 中恢复。明确还没执行的任务会继续执行一次；已完成回复补存时不会重新调用模型。
- Windows 已保存的模型 API key 不再因一次探测失败而持续不可用，保存失败后也可直接重试。超时、命令启动失败和进程退出保留各自诊断。
- 凭据操作改为异步。版本清单只读取状态快照，不再现场启动 PowerShell 查密钥；实际对话只读取所选配置。取消等待或配置在等待中改变时，不会迟到发起旧请求。
- Windows/Linux Console 保留连接、清单解析和版本校验的具体失败原因，避免沿用过期版本差异触发修复。
- 支持兼容客户端恢复中断的附件上传；旧连接不再堵住重传，校验失败可重新上传，已完成的临时分块会清理。旧客户端仍可使用原整文件上传接口。

## 更新

Mac 下载 DMG 替换应用，再按提示更新 Console 管理的 Core。Linux 提供 x64/arm64 Debian 安装包。
Windows 提供 x64 **未签名 preview** 安装包，安装方式与此前版本相同。
无需卸载、解绑或删除现有数据。发布安装包不会自动升级正在运行的服务器。

## 验证范围

发布前检查 Host 回归、Console、生成产物一致性，以及 Windows runner 上的真实 DPAPI、Scheduled Task、安装升级恢复和 NSIS 安装后启动。发布流水线还验证 macOS 签名/公证、Linux 两种架构安装和全部发布资产的 SHA-256。

这些是自动化环境的验证，不代表每台客户电脑都已验收，也不能据此认定此前所有“运行版本 unknown”都由凭据等待造成。独立服务器与客户设备仍需各自执行升级。
