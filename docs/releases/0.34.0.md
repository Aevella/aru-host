# Aru Host 0.34.0

这一版补齐电脑协作者执行、离线结果恢复和 Host 安装状态，配套 Aru iOS 0.3（202609301401）。手机与 Host 分别更新，手机更新不会替电脑安装 Host。

- Claude Code 可以实际运行电脑协作者对话，支持文字、工具审批、继续对话与取消；需要电脑上的 Claude Code 登录。当前真实账号验收来自 macOS；Windows 安装流程由 Windows CI 检查，不能替代 Windows 真实订阅账号验收。
- 手机断开后，Host 保留已接受任务的执行状态和已完成回复。重新连接后可以获取保存的结果与执行历史；重启恢复不会自动重做结果不确定的外部动作。
- 执行和投递记录改为独立记录存储，历史按页读取。升级保留旧 ledger 的原始备份，并支持中断后的恢复。已经迁移的实例拒绝回滚到不支持该格式的旧 Host；原始备份不能覆盖升级后新增的任务。
- Mac Console 分清连接现有 Host 与更新自己管理的 Host Core，显示实际运行版本，凭据按实例隔离。修复安装路径、驱动刷新和流式聊天稳定性。
- 整合 Host 源码与生成运行包，保留现有配对、协作者、对话、模型配置和加密凭据。Linux 原生旧凭据有一次性导入，现有凭据优先；导入失败不会静默清空密钥。

## 更新

桌面用户下载对应平台的新安装包并直接安装，不必先卸载。VPS 使用 `sudo aru-selfhost upgrade`。备份实例时保留整个数据与凭据目录；已保存 API Key 所需的密钥也属于备份的一部分。

## 验证范围

发布前重新运行核心与 Console 测试、生成运行包检查和安装器检查；使用隔离实例验证旧版升级、新版启动和重启、配对及加密凭据保留、记录迁移与旧版回滚拒绝。正式桌面产物由发布流水线检查并附校验和，macOS 包执行 Developer ID 签名与 Apple 公证。公开发布成功以实际资产和流水线结果为准。

发布前本机结果：核心 109 项通过、1 项平台跳过；Mac Console 42 项通过；生成运行包、Mac 安装器与 HTTP smoke 通过。实际候选 macOS Core 包从 0.33.1 安装升级到 0.34.0，配对身份和合成加密凭据保留，2 条执行记录与 1 条投递记录逐项一致，原始 ledger 备份逐字节一致；新版重启通过，旧格式回滚被拒绝且当前服务继续可用。这是隔离安装实例的真实进程检查，不是对所有用户设备或 Windows 订阅账号的验收。
