# Aru Host 0.33.0

这一版配合 Aru 的电脑协作者房间，让手机与电脑上的同一位协作者拥有各自的对话、设置和工作区。

- 支持电脑身份与头像更新、持久权限设置，以及删除身份时停止其正在执行的任务，包括代手机运行的主动消息。
- 手机与电脑可以只读查阅另一边的资料，保留各自的记忆，不进行双向覆盖。
- 通知支持加密的协作者名字与回复预览；旧客户端继续使用通用通知。
- 主动消息可以接续 Host 已经发出但手机尚未同步的内容，避免连续消息忘记刚刚说过的话。
- 提供已安装版本与协议能力信息，配合手机明确显示升级要求。
- 修正电脑执行手机主动回合时的权限归属，并支持撤回手机主动执行授权。

## 升级

直接安装新版，不需要先卸载。现有配对与数据保留。VPS 可使用 `sudo aru-selfhost upgrade`。

电脑房间的新界面由配套 Aru TestFlight 提供；请同时更新手机 App 和 Host。旧版 App 的已有连接仍可使用。
