# Aru Host 0.36.0

本版修复手机主动消息与外部唤醒的失败收尾，改善 Windows/Linux 连接设置和安装恢复。

- 手机可明确拒收无效主动投递，Host 停止重投；已导入但确认中断的正常消息仍可补确认。外部唤醒支持逐条移除无效输入及分页接收，失败条目不再挡住后续页。
- 主动规则丢失结算时按实际对话结果恢复状态；Codex 停止请求缺回执时核对目标线程，不误停其他对话。
- 修复 Anthropic 工具续接中的签名思考块与空文本回放，以及手机消息引用被误当成文件名校验的问题。
- Windows/Linux Console 可保存 HTTPS、Tailscale 远程连接地址，保留原局域网地址；保存前核对 Host 身份。
- 修复 Docker/Podman 可写挂载参数。后台容器自检失败可在本机 Console 查看具体步骤与错误。
- Windows 安装器正确读取 Unicode 配置，安装失败明确区分首次失败、成功回退与回退失败。Console 取消操作不再被必填字段拦住。

## 更新

手机端相关修复包含在 Aru TestFlight 0.5（202610120355）中；手机与 Host 需要分别更新。
Mac 下载 DMG 替换应用，再按提示更新 Console 管理的 Core。Linux 提供 x64/arm64 Debian 安装包，Windows 提供 x64 未签名 preview 安装包。独立/VPS 安装按原方式更新，无需卸载或删除数据。

发布安装包不会自动升级正在运行的服务器。共享 Codex 进程完全不响应时仍明确报告停止失败，不会强杀其他对话。

## 验证

合并提交 7599e4b 的 Host Core、Windows 安装生命周期、Linux 桌面和 macOS 15/26 CI 全部通过。
拒收恢复另有 24 项本地测试，覆盖持久化中断、重启、重复拒收与正常投递保留。
发布流水线执行 macOS 签名/公证、Windows/Linux 安装检查及全部 12 个发布资产的校验和核对。
真实客户设备验收与安装包发布是不同证据，Windows 包仍为未签名 preview。
